CI/CD & DEPLOYMENT ARCHITECTURE

On-Demand AWS Deployment & Quality Gate

Controlled release lifecycle: from local full-stack development to automated Postman/Newman validation, Amazon ECR image registry, and live HTTPS hosting on AWS App Runner.

1. Postman vs Controller Tests

Controller tests (MockMvc) test Java classes with mocked services. Postman with Newman tests the entire live running system.

  • MockMvc: Fast unit isolation (mocked DB & security).
  • Postman/Newman: Real HTTP network calls, real DB schema, real JSON serialization.

2. On-Demand Deployment

Manual activation ensures deployments occur only when intentionally decided, preventing unintended production breaks.

  • Triggered via GitHub Actions workflow_dispatch.
  • Automatic abort if any Postman test assertion fails.

3. Public AWS Endpoint

AWS App Runner pulls the container image from ECR, managing SSL certificates, environment variables, and auto-scaling.

  • Native HTTPS URL (no complex ALB configuration).
  • Zero downtime rollout on new image tags.
