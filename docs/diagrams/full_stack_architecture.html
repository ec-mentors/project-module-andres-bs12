Architecture & Data Flow Topology

React 19 SPA to Spring Boot & PostgreSQL

Complete component boundaries, state synchronization pipelines, bearer-authenticated HTTP wire protocols, and relational database persistence.

CLIENT LAYER

Decoupled API Client

UI components never construct raw HTTP headers. api.ts manages JSON serialization, Bearer headers, and response status validation in a single testable module.

AUTHENTICATION

Security Scoping

Endpoints enforce @PreAuthorize to ensure operations only affect rows owned by the authenticated Google OAuth user principal ID.

STORAGE

ACID Persistence

PostgreSQL persists presets in favorite_meals indexed by user_id with automatic UUID primary keys and millisecond audit timestamps.
